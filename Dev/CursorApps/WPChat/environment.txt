# Server File Operations Commands

The following commands can be used to manipulate files on the server remotely:

## Viewing and Finding Files
- `ssh user@server "ls -l /path/to/directory"` - List directory contents
- `ssh user@server "cat /path/to/file"` - Display file contents
- `ssh user@server "grep 'pattern' /path/to/file"` - Search for pattern in file
- `ssh user@server "find /path -name 'pattern'"` - Find files matching pattern
- `ssh user@server "tail -n [lines] /path/to/file"` - View the last [lines] of a file

## File Transfer Operations
- `scp -i /path/to/key.pem /local/file user@server:/remote/path` - Upload file to server
- `scp -i /path/to/key.pem user@server:/remote/file /local/path` - Download file from server

## File Manipulation Operations
- `ssh user@server "cp /source/file /dest/file"` - Copy a file on the server
- `ssh user@server "mv /source/file /dest/file"` - Move/rename a file on the server
- `ssh user@server "rm /path/to/file"` - Delete a file on the server
- `ssh user@server "chmod permissions /path/to/file"` - Change file permissions

## Complex Operations (via combined commands)
- Download file, edit locally, upload the modified file
- Use sed for simple find-and-replace operations in files via SSH
- Backup files before editing using the cp command

Note: For extensive editing, the recommended approach is to download the file, edit locally, and upload back to the server.
