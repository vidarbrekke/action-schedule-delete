# TuneTussle Judge Guide

Welcome, Judge! This guide will help you set up and run a TuneTussle game.

---

## Getting Started

1. **Create a Game:**
   - Open the TuneTussle app in your browser.
   - Click **Create Game**.
   - Enter your name, a game prompt (e.g., "90s Hip Hop"), and the number of rounds.
   - Click **Create Game**. You'll get a unique 6-character game code.

2. **Share the Game Code:**
   - Give the code to all participants so they can join.

3. **Wait in the Lobby:**
   - See a live list of participants as they join.
   - When everyone is ready, click **Start Game**.

---

## Running the Game

1. **Play the Song:**
   - For each round, play the song snippet on your device (audio is not streamed).
   - Use the provided YouTube link (shown in the Judge controls) for playback. (The system supports different music providers.)
   - If the link is missing or invalid, play the song manually.

2. **Monitor Buzz-Ins:**
   - Watch as players buzz in. The first to buzz gets to answer.

3. **Reveal the Answer:**
   - Click **Show Answer** to display the correct answer to all players after each round.

4. **Adjust Scores (if needed):**
   - Click **Adjust Score** to manually change a player's score.
   - Select the player, enter the new score, and confirm.

5. **Advance Rounds:**
   - When a round is complete, click **Next Round** (or **End Game** on the last round).

6. **Game Over:**
   - After the final round, all players see the results and winner(s).
   - You can start a new game if you wish.

---

## Judge Controls Reference
- **Show/Hide Answer:** Reveal or hide the correct answer for the current round.
- **Next Round / End Game:** Progress to the next round or finish the game.
- **Adjust Score:** Override any player's score (with confirmation).
- **YouTube Player:** Use the embedded player to play the song (if a link is provided). If the link is missing or invalid, play the song manually. The system supports different music providers.

---

## Tips & FAQ
- **What if a player joins late?**
  - They can join the lobby until you start the game.
- **Can I skip a round?**
  - No, but you can end the game early by clicking **End Game** on the last round.
- **How do I handle disputes?**
  - Use the **Adjust Score** feature to correct scores as needed.
- **Is there a time limit for answers?**
  - Yes, players must answer quickly after buzzing in.
- **Can I replay a song?**
  - Yes, replay the song on your device as needed.
- **What if I lose connection?**
  - The app will automatically attempt to reconnect and restore your game state.
  - If reconnection fails, refresh the page and rejoin with the same game code and name.
