# WP Customer AI Chatbot Documentation

This directory contains comprehensive documentation for the WP Customer AI Chatbot plugin. The documentation is organized into the following categories:

## Directory Structure

- **[development/](development/)** - Developer-focused documentation
  - [wp-customer-ai-chatbot-overview.md](development/wp-customer-ai-chatbot-overview.md) - Plugin overview and core functionality
  - [development-plan.md](development/development-plan.md) - Development roadmap and milestones
  - [git-workflow.md](development/git-workflow.md) - Git commit and push guide
  - [environment-setup.md](development/environment-setup.md) - Staging/development server information
  - [prompting.txt](development/prompting.txt) - LLM prompting strategies and examples

- **[rag/](rag/)** - Retrieval-Augmented Generation (RAG) documentation
  - [better-rag.md](rag/better-rag.md) - Ideas and approaches for improving RAG
  - [rag.md](rag/rag.md) - Core RAG process guide
  - [RAG_test_howto.md](rag/RAG_test_howto.md) - How to run and interpret RAG tests
  - [rag-settings-guide.md](rag/rag-settings-guide.md) - Settings tweaks and optimization

- **[setup/](setup/)** - Installation and configuration
  - [indexing-best-practices.md](setup/indexing-best-practices.md) - Best practices for indexing products in WooCommerce
  - [openrouter-setup.md](setup/openrouter-setup.md) - OpenRouter API setup guide
  - [supported-models.md](setup/supported-models.md) - List of supported LLM models

- **[troubleshooting/](troubleshooting/)** - Debugging and fixes
  - [debug.md](troubleshooting/debug.md) - Debugging log for AJAX failures
  - [nonce-troubleshooting.md](troubleshooting/nonce-troubleshooting.md) - WordPress nonce debugging guide

## How to Use This Documentation

1. If you're a new developer, start with [wp-customer-ai-chatbot-overview.md](development/wp-customer-ai-chatbot-overview.md) to understand the plugin's purpose and architecture.

2. For setting up a development environment, refer to [environment-setup.md](development/environment-setup.md) and follow the Git workflow in [git-workflow.md](development/git-workflow.md).

3. To understand the RAG implementation, read [rag-settings-guide.md](rag/rag-settings-guide.md) for optimization strategies.

4. For common issues, check the [troubleshooting/](troubleshooting/) directory.
